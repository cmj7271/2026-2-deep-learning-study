# 제공 최종 가중치의 결과

제공하는 A~E 최종 가중치를 각 CSV의 Test 분할로 평가한 수치다.
모든 공개 가중치의 학습 seed는 42다.

| 평가 데이터 | 모델 | 정답 | Accuracy | CE ↓ |
|---|---|---:|---:|---:|
| 기본 6품종 Test | A | 72/90 | 80.0% | 0.5004 |
| 도메인 Test | A | 123/150 | 82.0% | 0.6357 |
| 같은 도메인 Test | B · 원본만 | 123/150 | 82.0% | 0.6123 |
| 같은 도메인 Test | C · 원본 + 변형본 | 124/150 | 82.7% | 0.5609 |
| 개 25품종 Test | D | 420/500 | 84.0% | 0.4787 |

E의 머리 위치 Test 90장 mean IoU는 **0.6251**이다.
IoU는 정답과 예측 사각형의 겹침 정도이며 분류 정확도와 다른 지표다.
다른 Task의 수치를 서로 비교해 모델의 우열을 정하지 않는다.

## 수업에서 관찰할 내용

- A → B: 같은 구조를 유지하며 도메인 데이터로 Conv 일부와 기존 Head를 추가 학습한다.
  제공 모델에서는 정확도가 같고 CE가 낮아졌다.
- B ↔ C: 같은 A에서 각각 시작한다. C는 변형본을 추가했으며 Test 정답이 1장 늘었다.
  Validation 정확도는 B 80.0%, C 77.5%로, 모든 평가에서 개선된 것은 아니다.
- A → D/E: 같은 고정 특징을 새 품종 label과 위치 좌표에 재사용한다.

B는 원본 30장으로 16회, C는 원본·변형본 60장으로 32회 update하므로 차이에는 추가 입력과
더 많은 학습이 함께 포함된다. 순수한 변형 효과만 분리한 비교는 아니다.
성능 차이가 작아 크고 안정적인 향상으로 설명하지 않는다.
평가 수치는 제공 가중치와 CSV의 Test 분할에 한정한다.

데이터 분할과 학습 설정은 [README](README.md), 출처·가공은 [data/SOURCE.md](data/SOURCE.md)에 있다.
